SolderSight — PCB ship-gate, verified by Banyan Sapling

A cheap vision model decides if a circuit board can ship. Mubit's Banyan Sapling checks that decision — against the model's own notes, and against policy — and blocks the bad ones. Verdicts are live from the model (your browser calls it directly); cached real verdicts load instantly.

Does the ship decision survive the model's own notes?

Evidence is the vision model's own crop-by-crop notes — no dataset labels. On 00041003 the model wrote "visible short circuit", then the board was up for shipping.

Is the proposed disposition actually allowed?

The vision model proposes a disposition; Sapling verifies it against an independent inspection (AOI) reading + a written policy → SHIP / BLOCK / REVIEW. Start on the catch.

What this is

A vision model (gpt-4o-mini, via Mubit) triages PCB photos — but cheap models are confidently wrong, clearing defective boards as pass. Banyan Sapling is the check that catches them, two ways:

  • Trace audit — the ship claim vs the model's own notes. No answer key; the catch is self-contradiction.
  • Policy gate — the claim vs an independent AOI reading + a written spec. SHIP / BLOCK / REVIEW, fail-safe to human.

Sapling is open-weight (Apache-2.0): MubitLabs/banyan-sapling. This page calls its research-preview endpoint live from your browser (no auth); if it's cold-starting, it shows a cached real verdict — never a fabricated one.

Full app (FastAPI + React), tests, and the trace_demo.py / gate_demo.py runs: github.com/sneldao/soldersight.
