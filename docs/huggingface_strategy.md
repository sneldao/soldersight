# SolderSight — Hugging Face Space (as built)

**Status: DEPLOYED.** → https://huggingface.co/spaces/Papajams/soldersight-sapling
(direct app: https://papajams-soldersight-sapling.static.hf.space)

A living, linkable demo that shows Banyan Sapling doing the hard part — semantic
verification — on a visual, manufacturable domain (PCB QA). Free, permanent,
discoverable in the same community as the open-weight Sapling model.

> This file was originally a *plan* for a Gradio Space. Two facts changed the build;
> the plan below is updated to match what actually shipped.

## What changed from the original plan

1. **Gradio Spaces are no longer free.** HF now requires a PRO subscription to host
   Gradio/Docker Spaces even on free `cpu-basic` (`402 Payment Required`). **Static
   Spaces remain free for everyone** → we shipped a static Space.
2. **No backend needed.** The Banyan Sapling research-preview endpoint
   (`…endpoints.huggingface.cloud`) returns permissive CORS headers (it reflects any
   `Origin`, allows `POST` + `content-type`). So the static page calls Sapling
   **live from the browser** — no server, no auth, no spend. We verified this before
   committing to the static approach.

Net: the static Space is *better* for a demo than the Gradio plan — free, permanent,
instant (CDN, no cold start), and still genuinely live.

## What shipped (`static_space/`)

- `index.html` — self-contained app (inline CSS/JS). `gate_decision` from
  `backend/sapling.py` is ported to JS; the browser POSTs `{"inputs":{policy,
  evidence, claim}}` to the live endpoint and renders the real verdict.
- `cases.json` — demo cases (policy + trace) each with the exact Sapling inputs and a
  **real cached verdict** (generated by `hf_space/build_static.py` from the live model).
- `images/` — the board photos used by the cases.
- Tabs: **Trace audit** (claim vs the model's own notes — no answer key),
  **Policy gate** (claim vs AOI evidence + written policy → SHIP/BLOCK/REVIEW),
  **About**. The catch (`00041004` / `00041003`) is preloaded on first paint.

### Honesty model (the quality bar)
- **Live-first:** the "Run live via Banyan Sapling ↻" button calls the endpoint from
  the browser and shows a green "live" chip with the real calibrated probabilities.
- **Cached-real fallback:** if the endpoint is cold-starting, the page shows the
  bundled *real* cached verdict with a "cached real verdict" chip. **Nothing is ever
  fabricated** — there is no string-matched mock.

## Regenerating / redeploying

```bash
# refresh the cached real verdicts + payload (needs network)
cd hf_space && python build_static.py
# redeploy
hf upload Papajams/soldersight-sapling ./static_space . --type space
```

A Gradio version also exists in `hf_space/` (same logic, real client) as a reference
— deploy it only if a PRO Space is ever wanted.

## Why this helps Mubit's global launch

1. **A live, linkable demo** of "Banyan Sapling verification" they can point press/users at.
2. **A visual, non-software domain** (PCB manufacturing) — shows Sapling beyond code agents and support tickets.
3. **The no-answer-key trace audit** — the differentiator (cf. Fox/Trace Auditor), in a physical domain.
4. **Open-weights alignment** — Sapling is Apache-2.0 on HF; the Space lives in the same community and calls the model directly.
